# Plan Interview

Conduct a deep technical interview about the current plan using `AskUserQuestion` to surface gaps, ambiguities, edge cases, and potential issues.

## Process

1. Ask probing questions about missing details, undefined behaviors, unstated assumptions, error handling, and edge cases.
2. Update the plan based on answers.
3. Repeat until the plan is concrete, clear and complete for execution by an AI agent.
