# Running the Application

1. Open the solution:
   ```powershell
   .\AAPT-Antares-OperationalAgent\src\Agent>Agent.sln
   ```

2. Build and run the solution

3. The `Agent.Web` project will start a test chat client using your identity to access Azure resources.
