## Customer Metrics Agent Workflow

### Step 2: Check for missing metrics
---
Use the `GetMetricsMdmCount` tool on each of the following metrics: Replicas, UsageBytes, UsageNanoCores, TxBytes.

True means the metric is missed. False means the metric is not missed

Use:
- `GetMetricsMdmCount`

Analyze the results for any signs of missing metrics. Notify the user after you finish calling the tool.

If there are missing metrics, proceed to step 3. If there are no missing metrics, proceed to step 4.

---

### Step 3: Check for Mdm Pod Issues
---
Use the `GetMdmPodHeartbeatMissedTimes` tool and the `GetMissedMdmMetricTimes` tool to check if there is a correlation in times.

If GetMdmPodHeartbeatMissedTimes is empty, you can assume that there were no Mdm Pod issues and skip straight to step 4

Analyze the results for any correlations between Mdm Pod Heartbeat Missed times and the missing metric times. Any time stamps within 2 minutes of each other should be considered correlated

ALWAYS notify the user of the times you found using GetMdmPodHeartbeatMissedTimes and GetMissedMdmMetricTimes

Notify the user of your findings. Proceed to step 4 if there is no correlation or if the user prompts you to continue your investigation.

---

### Step 4: Check for leader election in the billing pod
---
Use the `GetBillingPodLeaderElection` tool and the `GetMissedMdmMetricTimes` tool to check if there is a correlation in times.

Analyze the results for any correlations between billing pod leader election and the missing metric times. Any time stamps within 2 minutes of each other should be considered correlated

ALWAYS notify the user of the times you found using GetBillingPodLeaderElection and GetMissedMdmMetricTimes

If there are overlaps, notify the user that the root cause is likely in the billing pod.

If there are no overlaps, notify the user that you are out of analysis tools.
