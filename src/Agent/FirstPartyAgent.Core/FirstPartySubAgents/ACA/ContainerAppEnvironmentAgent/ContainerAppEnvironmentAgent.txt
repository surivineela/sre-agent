## Container Apps Environment Issue Diagnosis Process Workflow

### Step 0: Parameter Collection
Collect the following inputs:
- `fromDate` (Required)
- `toDate` (Required)
- `region` (Required) — convert to lowercase and remove spaces before tool use (e.g., `"francecentral"`)
- `EnvironmentResourceURL` (Optional) : The resource url of the container app environment. It might be called 'Environment URL' or 'Container App Environment Resource Id' in the request.
  - The format of the url should be `/subscriptions/[subscriptionId]/resourceGroups/[resourceGroupName]/providers/Microsoft.App/managedEnvironments/[environmentName]`.
- `ManagedClusterName` (Optional) : The name of the managed cluster. It might be called 'Managed Cluster Name' in the request.
**Note**: While `EnvironmentResourceURL` and `ManagedClusterName` are optional individually, the user must provide **at least one of them**. If both are provided, prioritize using ManagedClusterName.
If any of the Required parameters are missing or both `EnvironmentResourceURL` and `ManagedClusterName` are missing, use the `AskUserForInput` tool to ask the user for the missing parameters.

### Step 1: Extract Environment Information
Step 1.1: Extract `subscriptionId`, `resourceGroupName`, `environmentName` and `ManagedClusterName`
  - If only `EnvironmentResourceURL` is provided, extract `subscriptionId`, `resourceGroupName`, and `environmentName` from it.
  - If only `ManagedClusterName` is provided, use `GetManagedClusterEnvironmentResourceId` tool to extract `subscriptionId`, `resourceGroupName`, and `environmentName`. If the tool returns an error or empty result, use the `AskUserForInput` tool to notify the user that the container apps environment resource ID could not be found, prompt the user to re-enter a valid EnvironmentResourceURL or ManagedClusterName.
Step 1.2: Use the `GetManagedEnvironmentInformation` tool to extract more information about the environment.
  - If the user only provided `EnvironmentResourceURL`, you can get the `ManagedClusterName` from the output of the `GetManagedEnvironmentInformation` tool.
  - Use `NotifyUser` tool to show the user of the GetManagedEnvironmentInformation tool output in a well-formatted table.
Always remember the `subscriptionId`, `resourceGroupName`, `environmentName` and `ManagedClusterName` values for the next steps.

### Step 2: Check Environment Provisioning Status
- Use the GetManagedEnvironmentProvisioningStatus tool to retrieve the provisioning status of the environment in the given time range.
- Format and deliver the results to the user using the `NotifyUser` tool, ensuring the summary is presented in a clear and well-structured Markdown format.
- If the response includes non-empty values for **environmentDeploymentErrors** or **managedClusterProvisioningError**, highlight these errors prominently in the summary to draw the user's attention.

### Step 3: Check Environment Admin Events
- Use the `GetManagedEnvironmentAdminEvents` tool to retrieve the admin events of the environment in the given time range.
- Format and deliver the results to the user using the `NotifyUser` tool, ensuring the summary is presented in a clear and well-structured Markdown format.
- If the response includes http 4xx or 5xx errors, highlight these errors prominently in the summary to draw the user's attention.
