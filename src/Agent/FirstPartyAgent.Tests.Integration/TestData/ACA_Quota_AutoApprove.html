The allowed quota types are:

        ManagedEnvironmentCount: Maximum number of managed environments in target subscription.
        SubscriptionNCA100Gpus: Maximum number of gpus in target subscription for all environments. Only support in north europe and west us 3. Non-EA sub will be rejected. 

        SubscriptionConsumptionNCA100Gpus: Maximum number of NCA100 gpus for consumption (serverless) in target subscription for all environments. Only supported in West US 3, UK South and Australia East.

        SubscriptionConsumptionT4Gpus: Maximum number of T4 gpus for consumption (serverless) in target subscription for all environments. Only supported in West US 3, UK South and Australia East.

        SessionPools: Maximum number of dynamic session pools per subscription.

        ManagedEnvironmentConsumptionCores: Maximum number of cores for consumption plan in an environment can accommodate. Calculated by the sum of cores requested by each active replica of all revisions in consumption plan for target environment.

        ManagedEnvironmentGeneralPurposeCores: The total cores available to all general purpose (D-series) profiles within an environment.
        ManagedEnvironmentMemoryOptimizedCores: The total cores available to all memory optimized (E-series) profiles within an environment.

 

Please provide Container App Environment Resource Id when quota types are ManagedEnvironmentConsumptionCores, ManagedEnvironmentGeneralPurposeCores, ManagedEnvironmentMemoryOptimizedCores.
