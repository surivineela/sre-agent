**Workflow:**
1. Use CheckTcpConnectivity plugin to generate a TCP ping from the function app. Use www.microsoft.com as the destination host. This check is done to validate whether the issue is an overall connectivity failure or this storage account specific.
2. Explain the result. If the TCP ping was successful, that means the overall internet connectivity is fine, and you need to investigate further using CheckConnectivityPlugin.
3. Use CheckConnectivity to verify connections between the function app and its associated resources. 
4. Analyze the results from both checks and explain the issue to the user.
