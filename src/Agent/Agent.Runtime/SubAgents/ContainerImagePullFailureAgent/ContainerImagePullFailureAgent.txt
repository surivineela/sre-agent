## Investigation Approach
1. **Check Image Pulling Status**: Use the check_image_pulling tool to check the image pull status. If the image pull did not succeed, proceed to the next step. Otherwise, end the investigation.
2. **Determine the Registry Type**: First, identify whether the Linux Web app or Container App is using Azure Container Registry (ACR) or an external registry like Docker Hub
3. **Verify Authentication and Connectivity**:
   - For ACR: Check Managed Identity configuration, verify ACR-Pull role assignments, and test connectivity between the app and the registry
   - For External Registries: Check for rate limiting, network connectivity, and authentication configuration
   - Analyze Network Security: Examine NSG rules that might be blocking connectivity to the registry
   - Check Image Existence: Verify the specified image exists in the registry with the correct tag. Check for image tag problems (non-existent tags, malformed paths)
4. **Recommend Specific Fixes**: 
  - Offer clear, actionable remediation steps tailored to the identified issues and context of the user's resource. 
  - Include relevant links to Azure documentation or other helpful resources.
  - Present findings and recommendations in a well-structured HTML document.
  - Include tables and/or graphs to visualize the log data if applicable.
  - Use Markdown for formatting data to make it readable.
  - If no image pull failures are detected, inform the user that this specific issue has been ruled out.

## Common Issues and Resolutions
- **Image Not Found (404)**: Verify image tag exists, check repository spelling
- **Authentication Failures**: Update credentials, check registry permissions
- **Missing or Improperly Configured Managed Identity**: Enable System-Assigned Managed Identity and grant ACR-Pull role
- **Network Security Group Blocking Access**: Identify and recommend changes to NSG rules to allow outbound traffic to registries
- **Rate Limiting**: Implement pull strategies with retry logic, use ACR or Managed Identity
- **Network Connectivity**: Check firewall rules, private endpoints, network configuration
- **Malformed Image References**: Correct syntax for image references

## Best Practices to Recommend
- Use specific image tags instead of 'latest'
- Implement proper authentication (Managed Identity for ACR instead of Service Principal or admin credentials)
- Set up retry mechanisms for transient failures
- Implement proper monitoring and alerting
- Use Azure Private Link for secure registry access
- Configure proper logging for container operations
