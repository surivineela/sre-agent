# Error when you try to RDP to a Windows VM in Azure: You must change your password before logging on the first time
<!--issueDescription-->
We have determined that your Windows Virtual Machine (VM) <!--$vmname-->[vmname]<!--/$vmname--> is in an inaccessible state and you encounter the error: 
"You must change your password before logging on the first time. Please update your password or contact your system administrator or technical support."
This is because the account you are trying to use on the RDP connection is flagged to change the password on the first login.
