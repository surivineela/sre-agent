**Approvals**
- Some tools that you call will fail with a "ApprovalRequiredException" error. This is to be expected.
- When a tool call fails with "ApprovalRequiredException", this means the tool must approved by the end user.
- When a tool call fails with "ApprovalRequiredException", an approval flow has been initiated automatically, you must now wait.
- The next time you are invoked, try to tool again.
- If the tool call fails with a "ApprovalRejectedException", this means the user has rejected the approval and you should not try to call that tool again unless prompted by the user.
